# Safety checklist

- [ ] No work on 220/230 V without supervisor
- [ ] Primary fuse / isolation transformer practices followed
- [ ] One hand rule / dry bench when live testing secondary if required by lab
- [ ] Capacitor discharged before rewiring
- [ ] No jewelry dangling into the breadboard
- [ ] DMM category rating appropriate for the measurement
- [ ] Heat-sink / ventilation for the 7805 under sustained load
- [ ] Power off before rearranging jumpers
